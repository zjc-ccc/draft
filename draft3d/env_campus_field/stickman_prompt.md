# 白色火柴人（校园操场比例参照）· 优化后的制作描述

> 来源：`blender_scene_prompt_template.md` 七段结构。用途是给 `env_campus_field.glb` 做人体尺度参照，所以本体不带场景，只做单体。

## 比例基准（写死，不许改）

- `env_campus_field.glb` 跑道外圈长 `7.6` 场景单位，视作 `200 m` → 1 单位 ≈ `26.32 m`。
- 人体身高 `1.7 m` → `1.7 / 26.32 = 0.0646` 场景单位。
- 所有尺寸按身高 `H = 0.0646` 等比推导，脚底落在原点 `z = 0`。

## 七段描述

**1 观看方式**
单体模型，以第三视角观察，可自由拖拽旋转缩放，无 UI。正面 `-Y` 朝向，便于直接摆进操场。

**2 载体与构图**
不设底座、不设地面，只有一个人形单体，脚底贴 `z = 0`，整体竖直居中、左右对称，头身比 1:7.5，站姿微微分开双脚，形体紧绷不松散。

**3 画面风格**
三渲二，纯白单体，无贴图、无五官、无衣物、无头发，材质干净，轮廓明确，靠剪影和关节球体读出人形，白色略带一点自发光以便在夜景/阴影里也保持纯白。

**4 主体与布局**
主体是一个标准站姿火柴人：球形头、短颈、直筒躯干、髋部连接球、左右两段式手臂（肩球 + 上臂 + 肘球 + 前臂 + 手球）、左右两段式腿（髋球 + 大腿 + 膝球 + 小腿 + 脚掌），四肢微微外张成 A 字，重心在双脚之间。

**5 元素清单**
球形头、颈部圆柱、肩部横梁、胸腔、腰部收窄、髋部球、上臂、肘关节球、前臂、手部球、大腿、膝关节球、小腿、脚掌薄板、脚踝连接处等；不要面部、不要手指、不要衣服褶皱。

**6 动态**
静态站姿即可；如果需要待机动画，只做极轻的呼吸起伏与手臂微摆，幅度不超过身高的 1/200，不影响比例参照。

**7 约束与质量**
不要底座、不要地面、不要投影贴图、不要颜色分区，全身只有一种白色材质；必须保证 1.7 m 比例可复现，必须脚底对齐原点，必须能直接导入 Godot 与操场模型同场景叠加。用 blender。
