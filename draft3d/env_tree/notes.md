# env_tree

## 基本参数

| 项 | 值 |
| --- | --- |
| 类型 | 3D 体素树（像素风 / voxel 感），静态单模型 |
| 尺寸 | 宽 2.2 m × 深 1.8 m × 高 3.8 m |
| 体素网格 | 0.2 m/格，整棵由 433 个体素合并而成 |
| 面数 | 622 面 / 1244 三角面（内部面已剔除） |
| 原地心 | 树根中心、地面 z=0（可直接落到地形上） |
| 源文件 | `src/env_tree.blend` |
| 导出 | `export/env_tree.glb`（59 KB，glTF 2.0） |

## 结构

- **树干**：3×3 体素截面，z=0～2.4 m，顶部略入树冠。
- **根突**：z=0 一层 5×5 削角（`|x|+|y| ≤ 3`）+ z=1 层四向伸出小根，形成阶梯式外扩，避免"裙边"整块板感。
- **树冠**：5 个椭球叠加（主体 / 右下枝团 / 左上枝团 / 顶部盖 / 左后侧补团），冠底不低于 z=2.0 m，保留 4 格裸树干。外壳按 12% 概率随机削掉，得到锯齿状轮廓而非光滑球面。
- **苔藓**：只点缀在根突外圈（z=0～1）与树干底部边缘，覆盖率约 20%，不侵入树冠。

## 材质

6 个纯色材质槽（程序化配色，**零贴图、零 UV**），色值沿用 2D 素材的木材/苔绿 ramp：

| 材质 | 色值 | 用途 |
| --- | --- | --- |
| `env_tree_bark_dark` | `#3E2A18` | 树皮暗部（约 12% 体素） |
| `env_tree_bark` | `#94663A` | 树皮主体 |
| `env_tree_bark_hi` | `#C08E4E` | 树皮高光（约 6%） |
| `env_tree_leaf_dark` | `#4A5824` | 树冠底部/背光 |
| `env_tree_leaf` | `#6E7C34` | 树冠主体 |
| `env_tree_leaf_hi` | `#9AAE52` | 树冠顶部受光 |

- 全部 `Principled BSDF`：Roughness 1.0、Metallic 0、Specular 0 —— 刻意去掉镜面高光，颜色在引擎里保持纯粹色块感。
- 所有面 `use_smooth = False`，硬边硬色，无渐变。

## 生成逻辑

程序化生成（非手捏），参数可控、可批量出变体：

- 体素颜色由确定性哈希 `(x,y,z)` 决定，同参数必得同一棵树（种子已固定）。
- 只需改椭球中心/半径即可得到不同冠形；改树干高度/根突层数可得老树、幼树。

## Godot 用法

```gdscript
var tree = preload("res://draft3d/env_tree/export/env_tree.glb").instantiate()
add_child(tree)
```

- 导入后为 `MeshInstance3D` + `env_tree` mesh，6 个材质槽自动挂上。
- **不要开 `Generate Tangents` / 平滑**；材质里 `Shading → 平滑` 保持关闭即为体素硬边。
- 如需批量摆放，用 `MultiMeshInstance3D` 更省，单模型 1244 三角面，几十棵不构成压力。
- 模型 Y 轴向上（glTF 标准），Godot 里无需旋转。
