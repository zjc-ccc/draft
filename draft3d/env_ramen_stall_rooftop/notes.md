# env_ramen_stall_rooftop

赛博朋克天台深夜拉面摊（Blender 5.2 / EEVEE / 三渲二）。

## 文件

| 路径 | 说明 |
| --- | --- |
| `src/build_ramen.py` | 主入口：集合、构建顺序、保存/导出/渲染 |
| `src/ramen_core.py` | 三渲二材质、基础几何、灯光相机、Freestyle、合成器、入场动画 |
| `src/ramen_roof.py` | 底座、屋顶、女儿墙、楼梯间、水箱、外机、晾衣绳、霓虹广告牌 |
| `src/ramen_stall.py` | 屋台主体、雨棚、暖帘、灯笼串、灯箱、操作台、折叠桌凳 |
| `src/ramen_props.py` | 纸箱、盆栽、猫窝、煤气罐、积水倒影、雨 |
| `src/export_glb.py` | 导出引擎友好材质版 glb（临时换 Principled，导出后还原） |
| `src/env_ramen_stall_rooftop.blend` | 生成结果，可直接打开渲染 |
| `export/env_ramen_stall_rooftop.glb` | glTF 2.0 导出（含入场动画） |
| `export/preview.png` | 1600×1000 主视觉预览（第 200 帧） |

## 重建

```powershell
# 构建 + 保存 .blend + 导出 glb
D:\Blender\blender.exe -b -P src\build_ramen.py

# 渲染主视觉
D:\Blender\blender.exe -b src\env_ramen_stall_rooftop.blend -o //../export/preview_#### -f 200
```

## 场景规格

- 单位：米。底座 10.4 × 10.4（台座高 0.76），天台地面 z = 0.35，四周女儿墙高 0.95。
- 全部元素落在 10 × 10 天台范围内，无人物；小猫仅有蜷睡剪影。
- 屋台：台车 3.5 × 1.8，台面高 1.43，车顶 3.05；正面开口宽 3.4，暖帘外挂于雨棚前沿（y ≈ 2.46）。
- 主视觉元素：红色塑料雨棚、蓝染暖帘（白字/白圆点）、4 只纸灯笼、立式灯箱、前脸红底白字招牌、24H 小霓虹、左侧幟旗。
- 操作台：不锈钢汤锅（含汤面自发光）、小锅、三层蒸笼、碗塔、砧板刀具、调料瓶、后墙双层货架与酒瓶、挂勺杆、菜单纸条、吊灯与热气。
- 天台环境：楼梯间出入口（亮窗/配电箱/门灯/天线）、不锈钢水箱（爬梯/管带）、两台空调外机、晾衣绳、霓虹广告牌（ラーメン / 深夜営業）、落水管、纸箱、盆栽、猫窝、煤气罐、5 处积水与霓虹倒影、520 条雨丝。
- 相机：44 mm，方向 `(0.54, 0.70, 0.46)` × 19.6 m，注视 `(0, 0.3, 1.62)`。
- 帧：24 fps，`frame_end = 209`。

## 材质与风格

- 三渲二：`Diffuse BSDF → Shader to RGB → ColorRamp（常量插值，4 级：0.30/0.48/0.72/1.00）→ 乘底色 → Emission`。
- 发光件（灯箱、灯笼、霓虹、汤面、窗）用纯 Emission，配合合成器 Bloom（Bloom / Threshold 0.65 / Strength 0.9 / Size 0.8）。
- 墨线：Freestyle（silhouette / border / crease / contour），绝对线宽 1.4 px，线色 `#050508`。
- 色彩管理 `Standard`，保持霓虹不被 AgX 去饱和。

## 灯光

- 月光 SUN 3.6（冷蓝）+ 背轮廓 SUN 1.5。
- 摊位内部 4 盏暖点光（420/260/240/180 W）、雨棚面光 170 W、台面补光 110 W、灯笼暖光 55 W、暖帘冷补光 50 W。
- 霓虹补光：粉 150 W、青 90 W；楼梯间门灯 70 W；正面/顶面冷色面光 220/120 W。

## 动画

- 分组错峰入场：底座与屋顶（1）→ 屋台与暖帘（26）→ 操作台内部（34）→ 楼梯间（40）→ 水箱（58）→ 灯笼（62）→ 广告牌/灯箱（70~72）→ 外机与杂物（96~104）→ 晾衣绳/桌凳（100~118）→ 积水（150）→ 雨（165）。
- `rise` = 从地面下方 0.9 m 升起；`pop` = 从 0.001 缩放弹入。

## 已知取舍

- 未使用透明玻璃：摊位正面完全敞开，仅用暖帘与雨棚组织层次，保证操作台在斜俯视角下可见。
- 积水为深色不规则面片 + 霓虹色条，无实时反射，靠明度与色相反差表达湿润。
- 字体依赖系统日文字体（Yu Gothic / Meiryo / MS Gothic）；缺失时灯箱与霓虹退化为发光条，场景仍可成立。
- 描边依赖 Freestyle，只在 Blender 渲染中出现；`.glb` 不含墨线，导入引擎需自行加描边后处理。
- 引擎版 glb 的材质由 `export_glb.py` 在导出瞬间替换为 Principled：
  `Base Color = 作者色`，`Roughness 0.9 / Metallic 0`，仅霓虹、灯笼、灯箱、窗、汤面、雨等发光件保留自发光（强度上限 1）。
  因此 glb 里是平涂底色，不含阶梯光照；阶梯感需要在引擎里用 toon shader 重建。
- glb 中每个对象各有一段入场动画（共 434 段），在引擎里可直接播放或忽略。
- 若用 Blender 打开 `.blend` 预览，需切到 Rendered 视口或按 F12；Solid 视口只显示灰色，Material Preview 用内置 HDRI，亮度与成片不同。
