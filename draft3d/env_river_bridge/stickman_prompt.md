# 白色火柴人（跨河桥比例参照）· 优化后的制作描述

> 来源：`blender_scene_prompt_template.md` 七段结构。用途是给 `env_river_bridge.glb` 做人体尺度参照，所以本体不带场景，只做单体。

## 比例基准（写死，不许改）

- `env_river_bridge.glb` 马路宽 `2.40` 场景单位，视作双向两车道 `7.0 m` → 1 单位 ≈ `2.917 m`。
- 人体身高 `1.7 m` → `1.7 / 2.917 = 0.583` 场景单位。
- 交叉验证：桥面宽 `1.70` 单位 ≈ `4.96 m`，桥下净空 `1.15` 单位 ≈ `3.35 m`，楼梯踢面 `0.12` 单位 ≈ `0.35 m`（略高于现实，属微缩夸张）。
- 所有尺寸按身高 `H = 0.583` 等比推导，脚底落在原点 `z = 0`。

## 七段描述

**1 观看方式**
单体模型，以第三视角观察，可自由拖拽旋转缩放，无 UI。正面 `-Y` 朝向，便于直接摆上桥面。

**2 载体与构图**
不设底座、不设地面，只有一个人形单体，脚底贴 `z = 0`，整体竖直居中、左右对称，头身比 1:7.5，站姿微微分开双脚，形体紧绷不松散。

**3 画面风格**
三渲二，纯白单体，无贴图、无五官、无衣物、无头发，材质干净，轮廓明确，靠剪影和关节球体读出人形，白色略带一点自发光以便在夜景/阴影里也保持纯白。

**4 主体与布局**
主体是一个标准站姿火柴人：球形头、短颈、直筒躯干、髋部连接球、左右两段式手臂（肩球 + 上臂 + 肘球 + 前臂 + 手球）、左右两段式腿（髋球 + 大腿 + 膝球 + 小腿 + 脚掌），四肢微微外张成 A 字，重心在双脚之间。

**5 元素清单**
球形头、颈部圆柱、肩部横梁、胸腔、腰部收窄、髋部球、上臂、肘关节球、前臂、手部球、大腿、膝关节球、小腿、脚掌薄板、脚踝连接处等；不要面部、不要手指、不要衣服褶皱。

**6 动态**
带 17 根骨骼的骨架，五个动作片段：`idle`（呼吸起伏）、`walk`（24 帧循环）、`run`（20 帧循环、身体前倾）、`jump`（下蹲—蹬伸—腾空收腿—落地缓冲，37 帧一次性）、`wave`（右臂抬起、前臂摆动，49 帧一次性）。竖直位移由引擎驱动，动画只负责姿势。

**7 约束与质量**
不要底座、不要地面、不要投影贴图、不要颜色分区，全身只有一种白色材质；必须保证 1.7 m 比例可复现，必须脚底对齐原点，必须能直接导入 Godot 与跨河桥模型同场景叠加。用 blender。

## 验证结果

回导 `export/stickman_white.glb` 实测包围盒：`X ±0.135`、`Y ±0.039`、`Z 0 ~ 0.583`，脚底严格在 `z = 0`，总高 `0.5829`。

glb 结构：28 个网格节点 + 17 根骨骼（1 个 skin、17 joints）+ 5 个动画片段，每个片段 51 条通道（17 骨 × 旋转/位移/缩放），435 KB。

## 骨架与蒙皮

- 骨骼链：`hips → spine → chest → neck → head`，两侧 `upperarm → forearm → hand` 与 `thigh → shin → foot`，共 17 根。
- **刚性绑定**：每个部件只有 1 个顶点组、权重 1.0，圆柱不会随动作被拉伸；关节球跟随下游骨骼（肘球跟 `forearm`、膝球跟 `shin`），因此弯曲时关节处不会露缝。
- 骨骼头部对准原有关节球圆心，旋转轴与人体关节一致。

## 动作制作要点

- 姿势用**世界轴角度**书写：`set_rot()` 内部做 `M⁻¹ · R · M` 变换，把世界轴旋转转成骨骼局部四元数，避免逐根骨骼猜局部轴向。
- 绕 `+X` 正角度 = 肢体向前摆（角色朝 `+Y`），负角度向后；挥手绕 `Y` 轴抬臂。
- 下蹲时髋部下沉量按腿长几何反算：大腿 `0.255H` + 小腿 `0.253H`，屈膝 40°/70° 时髋需降 `≈0.09H`，这样脚掌仍贴地。
