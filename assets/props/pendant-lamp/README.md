# pendant-lamp

## 用途

复古吊灯：顶部吸顶盘、一根长电线、黄铜锥形灯罩，灯罩下面露出一颗灯泡。有关灯（`off`）和开灯（`on`）两种状态，开灯时灯泡和灯口内壁发暖光，另有单独的光晕贴图给引擎做叠加发光。挂在天花板上当场景照明或可交互灯具（拉一下开关 / 通电）。

## 规格

| 项 | 值 |
| --- | --- |
| 画布 | 64x128 |
| 状态 | `off` 1 帧，`on` 8 帧 |
| 帧率 | 8 fps（只作用于 `on`，`off` 是静帧） |
| 动画时长 | 1 秒 / 循环 |
| 调色板 | 黄铜（`#B48A4C` / 高光 `#E2BA76` / 暗部 `#6A4A28`），氧化绿 `#5E6442`，电线 `#2C2019`，灯泡暖光 `#FCD684` / 白 `#FFF8DC` |
| 锚点 | 顶部居中（吸顶盘中心 x=32，吸顶盘在 y=2~9）；贴天花板时把 sprite 顶端对齐天花板 |

## 动画状态

| 状态 | 帧数 | 文件前缀 | 说明 |
| --- | --- | --- | --- |
| off | 1 | `pendant-lamp_off_` | 灯灭：灯泡是灰玻璃，灯口内壁是暗的 |
| on | 8 | `pendant-lamp_on_` | 灯亮：灯泡亮到近白，灯口内壁被照暖，8 帧亮度轻微呼吸 |

`on` 的 8 帧亮度是 `1.00 / 0.96 / 0.92 / 0.95 / 0.99 / 1.00 / 0.90 / 0.95`，整体很稳，只有第 6、7 帧轻轻一沉，像老灯泡快不行了；循环无缝，切帧不会跳。

## 发光贴图（glow）

`export/pendant-lamp_glow_00.png` 是 96x96 的暖黄光圈，**中心对齐灯泡中心**（在灯体里是 x≈32、y≈118）：

- 中心 alpha 0.69，往外平滑衰减到 0，颜色从暖白过渡到橙黄
- 专门给加法混合用，不需要再用像素画的方式抠边
- 默认 1 倍大小就够一层灯光；要照亮一间屋子可以放大到 1.5~2 倍，或者再叠一个 `PointLight2D`

## 在 Godot 里怎么用

```gdscript
# 1. 灯体本身：按状态切动画
lamp.play("off")           # 或 lamp.play("on")

# 2. 光晕：挂在灯泡位置的 Sprite2D，加法混合
var glow := Sprite2D.new()
glow.texture = preload("res://.../pendant-lamp_glow_00.png")
glow.position = Vector2(0, 48)   # 96x96 贴图的中心落到灯泡处（按灯体贴图坐标换算）
var mat := CanvasItemMaterial.new()
mat.blend_mode = CanvasItemMaterial.BLEND_MODE_ADD
glow.material = mat
```

想省事也可以用 `PointLight2D`，把同一张 glow 贴图设成它的 `texture`、`energy` 调到 1~2，让引擎去算光衰减；两种方式都行，**别把光晕直接烘进帧里**，缩放会糊，也没法随场景亮度调整。

## 细节

| 位置 | 说明 |
| --- | --- |
| 吸顶盘 | 顶部黄铜圆盘，下面收一个小接头，顶面有高光和一粒灰 |
| 电线 | 1px 深棕，画成一条细线、不描边，所以不会显得粗；每隔一段有一道浅色绞纹 |
| 灯头 | 黄铜短圆柱 + 灯罩上沿的卡圈，下半截被灯罩挡住 |
| 灯罩 | 锥形，左亮右暗五级黄铜色阶（硬边，不做抖动），上沿一道箍、中段一道接缝 |
| 卷边 | 灯罩底沿两行亮边 + 一行暗底，灯亮时内壁朝暖色偏 |
| 灯泡 | 关灯是灰玻璃加灯丝，开灯是暖白核心 + 橙色边，灯丝提亮 |
| 氧化 | 灯罩上四块黄绿锈斑，和底色混合过，不是贴上去的色块 |
| 积灰 | 灯罩卷边和吸顶盘上散落几粒 |

## 备注

- `off` 只有 1 帧，`on` 才有 8 帧；README 的 `frames: 8` 指的是 `on` 的帧数，播 `off` 时按静帧处理
- 光晕是独立文件，文件名里的 `glow_00` 只是为了让预览器能分到一个状态，实际不是动画帧
- 灯体本身没有发光；发光只有灯泡、灯口内壁和那张 glow 贴图
- 想要“通电时闪两下才亮”，可以在 on 的第 0~2 帧之前插一次 off，或者用代码把 `on` 从头播一遍并临时降低 modulate
