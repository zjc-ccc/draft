# water-dispenser

## 用途

场景里的饮水机。玩家和它交互（接水）时，按剩余水量切换到对应的档位，水量见底就换成空桶。可以放在厨房、办公室、休息室这类场景里当可交互道具。

动画内容：桶里 6 个气泡从瓶颈往上浮到水面，冷水口下方飘一缕冷气，热水口不动。空桶档位没有气泡，所以 8 帧画面一致。

## 交互用法

游戏里用一个 0~1 的 `water` 变量记录水量，按下面的规则选状态：

| water | 状态 |
| --- | --- |
| > 0.875 | level-100 |
| 0.625 ~ 0.875 | level-75 |
| 0.375 ~ 0.625 | level-50 |
| 0 ~ 0.375 | level-25 |
| = 0 | level-0 |

每接一杯水把 `water` 减一个固定量（例如 0.1），跨过阈值时切状态即可。状态的帧文件名后缀是两位帧号，直接按 `00..07` 循环播放，8 fps。

## 细节

| 位置 | 说明 |
| --- | --- |
| 水桶 | 倒插在机身顶部，玻璃壁 2px（外层深边 + 内层亮边），玻璃内铺了一层淡蓝底，空桶也能看清轮廓 |
| 水面 | 始终是水平线，从瓶颈往上灌；水位越低压得越靠近桶口 |
| 水色 | 左侧亮、右侧深，做出圆柱的体积感 |
| 热水口 | 左侧，红色阀体 + 红色把手 |
| 冷水口 | 右侧，蓝色阀体 + 蓝色把手 |
| 接水盘 | 凹槽底部，竖条格栅 |
| 指示灯 | 机身右上角 1px 绿点 |

## 备注

- 五档是离散的，如果游戏需要更平滑的水量变化，可以只保留 `level-100` 和 `level-0`，中间用缩放/遮罩裁剪水位
- 冷气和气泡都是每档独立循环，切换档位时从第 0 帧开始不会跳帧
- 桶口卡座画在顶板两侧，瓶颈下段被机身挡住，看起来是插进去的
