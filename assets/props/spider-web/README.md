# spider-web

## 用途

场景装饰用的蛛网，贴在墙角、地牢、洞穴这种地方。蜘蛛是独立素材（`characters/spider`），在游戏里叠在这张网上移动，网本身不用动。

## 规格

| 项 | 值 |
| --- | --- |
| 画布 | 96x96 |
| 帧数 | 1（静帧） |
| 帧率 | 0 fps |
| 调色板 | 冷灰蓝蛛丝（`#F0F8FC` 亮丝、`#CEDEEA` 主丝、`#BACAD8` 弱丝），带透明度 |
| 锚点 | 居中（网心在 48,48） |

## 结构

| 元素 | 数量 | 说明 |
| --- | --- | --- |
| 放射丝 | 12 条 | 从网心拉到半径约 43px，每条的角度和长度都略有抖动 |
| 捕捉丝 | 1 条 | 从网心向外绕 4.5 圈的多边形螺旋，每经过一根放射丝往外跳一格 |
| 网心 | 1 圈 | 半径约 5.5px 的小圈，蜘蛛一般停在这里 |
| 锚丝 | 4 条 | 外圈拉到画布四角，表示网是挂在空间里的 |
| 断丝 | 2 条 | 垂下来的残丝，增加手工感 |

蛛丝用 alpha 绘制（200~240），叠在深色背景上偏亮、浅色背景上偏淡。网心留空，方便把蜘蛛摆在中间。

## 备注

- 网是整圆，需要半张网或破网可以调 `spider_web.py` 里的角度范围和环数
- 配套蜘蛛：`assets/characters/spider/`（32x32，四方向 12 帧）
