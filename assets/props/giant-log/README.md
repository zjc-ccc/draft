# giant-log

## 用途

角色砍树后掉落的巨大原木，后续可加工成木板、木棍。也适合当场景里的资源节点或临时障碍。

## 规格

| 项 | 值 |
| --- | --- |
| 画布 | 64x64 |
| 实际占用 | 约 58x24（上下留白，方便摆在地面上） |
| 帧数 | 1（静帧） |
| 帧率 | 0 fps |
| 锚点 | 底部居中（图像底部 y≈43） |
| 调色板 | 树皮 7 阶暖棕 + 断面 4 阶米黄 |

## 结构

侧视横放的圆柱：

- 外圈树皮：横向褶皱线（带断点）、三道短纵向裂纹、一个树疤
- 右端切面：树皮断口 + 三圈年轮 + 髓心 + 一道裂纹
- 上沿一条受光高光，下沿压暗，做出圆柱体积
