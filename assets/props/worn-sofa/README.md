# worn-sofa

## 用途

破旧的双人沙发，正面平视。整片靠背横跨沙发，两侧各一只扶手，座垫分成左右两块；深棕布面、暗黄色污渍、边角积灰，两个靠枕乱堆在左边。可以当纯装饰，也可以当可交互的坐具（坐下 / 搜索 / 藏东西）。

## 动画状态

| 状态 | 帧数 | 文件前缀 | 说明 |
| --- | --- | --- | --- |
| idle | 8 | `worn-sofa_idle_` | 5 粒灰尘在靠背上方慢慢飘，沙发本身不动 |

灰尘路径是按正弦漂移算的（每帧移动 1~2 px），循环无缝；沙发上的静态积灰点（靠背顶、两侧扶手顶、座垫前沿、座垫和靠背之间的缝）不随帧变化。

## 细节

| 位置 | 说明 |
| --- | --- |
| 靠背 | 一整片横跨整张沙发，分成左右两块；明显高出两侧扶手，顶部有滚边 |
| 座垫 | 左右两块并排，中间一道缝；顶面提亮、前沿压一道缝线，做出厚度 |
| 扶手 | 左右各一只，画在最前面，盖住靠背和座垫的两端；顶面有高光、内侧有暗边 |
| 靠枕 | 两个：一个斜靠在靠背上（约 -14°），一个歪倒在座垫上（约 +18°），都堆在左边 |

| 灰尘 | 沿各条顶边和缝隙分布的小灰点，外加 8 粒随机灰点 |

## 备注

- 为了能看见横跨整张沙发的靠背，这一版是正面平视；如果横版场景需要纯侧视（只能看到一只扶手），要另做一个侧视版本
- 靠枕是画在沙发里的，不能单独拿走；要拾取靠枕的话可以另外拆一个道具素材
- 污渍和静态积灰画在每一帧上，切帧不会闪
- 如果游戏只需要静帧，取 `worn-sofa_idle_00.png` 即可，元数据的 `frames`/`fps` 不用改（其余帧是同一张图加灰尘漂移）
