# worn-sofa

## 用途

破旧的双人沙发，侧视，适合横版场景和俯视房间的侧墙装饰。深棕布面、暗黄色污渍、边角积灰；两个靠枕乱堆在左边。可以当纯装饰，也可以当可交互的坐具（坐下 / 搜索 / 藏东西）。

## 动画状态

| 状态 | 帧数 | 文件前缀 | 说明 |
| --- | --- | --- | --- |
| idle | 8 | `worn-sofa_idle_` | 5 粒灰尘在沙发上方慢慢飘，沙发本身不动 |

灰尘路径是按正弦漂移算的（每帧移动 1~2 px），循环无缝；沙发上的静态积灰点（靠背顶、扶手顶、坐塾前沿、靠背和坐塾之间的缝）不随帧变化。

## 细节

| 位置 | 说明 |
| --- | --- |
| 靠背（右） | 左上角大圆角，做出后倾的斜肩；顶部有滚边 |
| 坐塾（中） | 顶面中间向上拱起，避免看成床板；前沿有一道缝线 |
| 扶手（左） | 画在靠枕前面，所以靠枕看起来是塞进扶手和靠背之间的 |
| 靠枕 | 两个：一个斜靠扶手（约 -16°），一个歪倒在坐塾上（约 +19°），都堆在左边 |
| 污渍 | 6 块暗黄污渍，边缘是不规则抖动，不是整齐的椭圆 |
| 灰尘 | 沿各条顶边和缝隙分布的小灰点，外加 8 粒随机灰点 |
| 木框 / 腿 | 坐塾下面露出一截木横档，两条收窄的木腿 |

## 备注

- 侧视只能看到近处的一侧扶手；如果场景需要正面能看到两个扶手，需要另做一个正面版本
- 靠枕是画在沙发里的，不能单独拿走；要拾取靠枕的话可以另外拆一个道具素材
- 污渍和静态积灰画在每一帧上，切帧不会闪
- 如果游戏只需要静帧，取 `worn-sofa_idle_00.png` 即可，元数据的 `frames`/`fps` 不用改（其余帧是同一张图加灰尘漂移）
