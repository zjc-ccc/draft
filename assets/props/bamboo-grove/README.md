# bamboo-grove

## 用途

一小片竹林：六根成熟的青竹挤在一个土堆里，竹根笔直地扎在土里，越高越各自朝外散开，每根竹梢都长着竹叶。适合摆在场景里当背景植被、院子角落的装饰，或者切一半当灌木用。整片会随风轻轻摆，土堆和一截竹根不动。

## 动画状态

| 状态 | 帧数 | 文件前缀 | 说明 |
| --- | --- | --- | --- |
| sway | 8 | `bamboo-grove_sway_` | 竹梢被风吹得轻轻摆，摆动幅度从竹根往上按 t² 增加，竹根和土堆完全不动 |

摆动是按每根竹子自己的相位算的，六根不同步，所以看起来是各摆各的、不会整片一起晃。第 0 帧和第 8 帧首尾相接，循环没有跳帧。

## 细节

| 位置 | 说明 |
| --- | --- |
| 竹竿 | 每根 3~6px 粗，越往上越细；曲线 `x = 竹根 + (竹梢 - 竹根) * t^2.0~2.6`，所以底部笔直、越高越往外弯 |
| 明暗 | 竹竿左边一列高光、右边一列暗部、内部一级中调，圆柱感是硬边分列，不做抖动 |
| 竹节 | 每隔约 10% 高度一道节，节处收窄 1px，上一行浅色节环 + 下一行暗色，像一圈箍 |
| 竹叶 | 梭形叶片，中段约 2px 宽，上半边亮、下缘一道暗绿、叶尖压暗；每根四丛侧叶（t≈0.58/0.69/0.80/0.90，按相位错开高度）+ 梢头一丛 |
| 叶丛 | 短枝朝外斜下，两三片叶子沿枝垂下、近乎平行，所以叶丛是往下垂的，不是撑开的圆球 |
| 描边 | 竹竿和土堆描墨色边，竹叶只描一圈暗绿，避免叶子被黑边吃掉 |
| 土堆 | 椭圆（中心 52,160，半径 26x13），上亮下暗三档土色，撒了点深色土粒 |
| 草 | 土堆上七簇草，每簇 3~6px 高，颜色比竹叶更黄一点 |
| 落叶 | 土堆上六片枯叶/暗叶，3~4px 长的小横条，不是飘在空中的 |

## 在 Godot 里怎么用

```gdscript
# 场景装饰：AnimatedSprite2D + SpriteFrames
var frames := SpriteFrames.new()
frames.add_animation("sway")
frames.set_animation_speed("sway", 6.0)
frames.set_animation_loop("sway", true)
for i in 8:
    frames.add_frame("sway", load("res://assets/props/bamboo-grove/export/bamboo-grove_sway_%02d.png" % i))

var grove := AnimatedSprite2D.new()
grove.sprite_frames = frames
grove.centered = false          # 锚点在左下，方便直接当地面物件摆
grove.play("sway")
```

如果想让它跟着风的方向摆得更明显，可以在 `AnimationPlayer` 里给整片加一点点 `skew` 或者用 shader 做顶点偏移，**别改帧本身**——帧是按固定幅度画的，缩放会糊。

## 备注

- 画布是 96x160 的竖长条，宽度只够一小丛；要更宽的竹林就并排摆两份，稍微错开 y 轴，别镜像（镜像会让竹叶的受光方向反过来）
- 竹根那截故意被土堆盖住，所以看不到断口；如果要把竹林插在斜坡上，可以只截上半段当"从坡上垂下来"的竹枝
- `status` 还是 `wip`：后续想加 `rustle`（风大一点）或 `night`（压暗）状态的话，直接在同一套帧上改色/加振幅就行
