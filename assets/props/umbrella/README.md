# umbrella

## 用途

角色手持的雨伞道具，也适合放进场景当装饰、当拾取物或当作天气系统的道具。8 帧覆盖从收到开的全过程，游戏里正向播放=打开，倒放=收起。

## 规格

| 项 | 值 |
| --- | --- |
| 画布 | 48x64 |
| 帧数 | 8（收起 → 打开） |
| 帧率 | 12 fps（整段约 0.58 秒） |
| 调色板 | 蓝绿渐变：伞顶 `#14383A` → 伞沿 `#A6F0DC`；伞杆金属灰、手柄木色 |
| 锚点 | 底部居中（手柄末端） |

结构：伞尖在上、伞面居中、伞杆竖直向下、木质 J 形手柄在下。

## 动画状态

| 状态 | 帧数 | 文件前缀 |
| --- | --- | --- |
| open | 8 | `umbrella_open_` |

帧 00 = 完全收起，帧 07 = 完全打开，中间帧是连续过渡。

| 帧 | 伞面半宽 | 说明 |
| --- | --- | --- |
| 00–01 | 5 → 6.9 | 收拢，能看到折痕和束带 |
| 02–04 | 8.6 → 11.4 | 伞骨撑开，伞面还比较窄 |
| 05–06 | 13.9 → 16.5 | 接近完全打开，伞沿开始出现波浪 |
| 07 | 20 | 完全打开，伞沿下垂、布面在伞骨之间下凹 |

游戏里的用法：

- 打开：00 → 07 顺序播放
- 收起：07 → 00 倒序播放（或做成反向动画资源）

## 图标

| 尺寸 | 文件 | 用途 |
| --- | --- | --- |
| 32x32 | `preview/umbrella_icon_32.png` | 物品栏 / 背包列表 |

简化处理：去掉伞骨细线和折痕，只留伞面轮廓、伞片明暗、金属伞尖和木质手柄，保证 32px 下依然能认出是雨伞。

## 渐变

伞面从伞顶到伞沿做蓝绿渐变（越靠伞沿越亮），左右再加一层受光差：左半边偏亮、右半边偏暗，让圆顶有体积感。伞片之间用深色伞骨线分隔，伞沿在两根伞骨之间下垂形成扇贝边。

## 备注

- 没有画投影，落地阴影交给引擎或场景处理
- 只做了「打开」一个方向的序列帧，收起用倒放，避免维护两套帧
- 需要的话可以再加 16x16 图标、收起态的独立静帧，以及「合拢带伞套」变体
