# spider

## 用途

在蛛网上来回爬的蜘蛛。配合 `props/spider-web` 使用：蛛网当背景，蜘蛛按移动方向切换状态叠在上面。也可以拿来当小怪、洞穴装饰生物。

## 规格

| 项 | 值 |
| --- | --- |
| 画布 | 32x32 |
| 帧数 | 每方向 12 帧（共 48 张） |
| 帧率 | 12 fps |
| 动画时长 | 1 秒 / 循环 |
| 调色板 | 深紫身体（`#4E3C66` / `#705A8E` / `#362848`），亮紫腿（`#786296`），亮蓝眼（`#68D8FF`） |
| 锚点 | 居中（身体中心在 16,16 附近） |

## 动画状态

| 状态 | 帧数 | 文件前缀 | 说明 |
| --- | --- | --- | --- |
| up | 12 | `spider_up_` | 向画面上方爬 |
| right | 12 | `spider_right_` | 向画面右方爬 |
| down | 12 | `spider_down_` | 向画面下方爬 |
| left | 12 | `spider_left_` | 向画面左方爬 |

步态：交替四足（左 1/3 + 右 2/4 一组，另一组反相），腿沿行进方向前后摆 2px 左右，抬腿时往回收，身体有 1px 的上下起伏。

## 方向是怎么来的

只画了一套「朝上」的帧，再整体旋转 90° / 180° / 270° 得到右、下、左三个方向。所以四个方向在形状上完全一致，改一处等于四个方向一起改。
